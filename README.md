# Projenin Ad: Kod-Asistan ve.1 
## Projenin Amac1: Kullanıcılara günlük işlerinde (hesaplama, selamlama vb.) yardımcı olacak bir dijital asistan tasarlamak 
## Projenin Hedefleri: v1.0 Akıll1 Menü, v2.0 Veri Saklama 
## Projenin Kapsamı: 
1.​Başla  
2.​Eğer su seviyesi > 50 ise 4. Adıma git  
3.​Değilse kapakları kapalı tut Adım 2'ye git  
4.​Adım: Tahliye saatini ve kritik su seviyesini yazdır  
5.​Bitir
